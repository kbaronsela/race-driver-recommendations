# משלנו — אינדקס בעלי מקצוע בשדה ורבורג

השם המוצג באתר הוא "משלנו"; שם התיקייה והמזהים הפנימיים נשארים mishelanu.

אתר עצמאי עם אפליקציה הניתנת להתקנה מהטלפון. התיקייה הזו שלמה בפני עצמה ואינה תלויה בשאר הריפו.

## מה יש

- **אינדקס** עם חיפוש (שם, תחום, טקסט, כתובת) וסינון לפי תחום.
- **הוספה** פתוחה לכולם: שם, תחום, טלפון, כתובת, טקסט חופשי, עד 8 תמונות וסימון מקום על המפה.
- **עמוד לכל בעל מקצוע**: חיוג, וואטסאפ, ניווט ב-Waze ומפה קטנה.
- **מפת המושב** עם כל העסקים שסומנו.
- **עריכה ומחיקה** — רק למנהל/ת האתר.

## הרצה מקומית

```bash
python mishelanu/app.py
```

ולפתוח http://localhost:5002 — או לחיצה כפולה על `mishelanu/run.bat`.

## מנהל/ת האתר

פעם אחת: `python mishelanu/set_password.py`. הסיסמה נשמרת בקובץ `config.json` שאינו נשלח לגיט.
במקום זה אפשר להגדיר משתני סביבה `MISHELANU_USER` ו־`MISHELANU_PASSWORD`.

## מבנה

| נתיב | תוכן |
|---|---|
| `app.py` | השרת (Flask): דפים, טפסים, הרשאות |
| `db.py`, `media.py` | מסד נתונים, טיפול בתמונות |
| `templates/`, `static/` | דפים, עיצוב, סקריפטים |
| `manifest.json`, `sw.js` | אפליקציה (PWA) |
| `data/`, `uploads/` | נוצרים בזמן הרצה — הנתונים והתמונות |

## פריסה

הנתונים נשמרים בקבצים, ולכן דרוש אחסון שנשמר בין הפעלות. האתר רץ על PythonAnywhere, מתוך אותו שרת
של אתר ההמלצות, בנתיב `/mishelanu/` — החיבור נמצא בסוף הקובץ `server.py` שבתיקיית השורש.

### עדכון על PythonAnywhere

1. במסוף Bash: `cd ~/race-driver-recommendations && git pull`
2. באותו מסוף: `source venv/bin/activate && pip install -r requirements.txt`
3. בלשונית Web, ב-Environment variables: `MISHELANU_USER`, `MISHELANU_PASSWORD`,
   וגם `MISHELANU_SECURE_COOKIES=1` (האתר מוצפן).
4. ללחוץ על Reload, ולפתוח `https://racedriver.pythonanywhere.com/mishelanu/`

הנתונים והתמונות נשמרים שם בתיקיות `mishelanu/data` ו-`mishelanu/uploads`, ואינם נמחקים בעדכון.
אם mishelanu לא נטען — אתר ההמלצות ממשיך לעבוד כרגיל, ובנתיב `/mishelanu/` מופיעה הודעה שהאתר אינו זמין.
