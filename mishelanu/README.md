# mishelanu — אינדקס בעלי מקצוע בשדה ורבורג

אתר עצמאי עם אפליקציה הניתנת להתקנה מהטלפון. התיקייה הזו שלמה בפני עצמה ואינה תלויה בשאר הריפו.

## מה יש

- **אינדקס** עם חיפוש (שם, תחום, טקסט, כתובת) וסינון לפי תחום.
- **הוספה** פתוחה לכולם: שם, תחום, טלפון, כתובת, טקסט חופשי, עד 8 תמונות וסימון מקום על המפה.
- **עמוד לכל בעל מקצוע**: חיוג, וואטסאפ, ניווט ב-Waze ומפה קטנה.
- **מפת המושב** עם כל העסקים שסומנו.
- **עריכה ומחיקה** — רק למנהל/ת האתר.

## הרצה מקומית

```bash
python mishelanu/app.py
```

ולפתוח http://localhost:5002 — או לחיצה כפולה על `mishelanu/run.bat`.

## מנהל/ת האתר

פעם אחת: `python mishelanu/set_password.py`. הסיסמה נשמרת בקובץ `config.json` שאינו נשלח לגיט.
במקום זה אפשר להגדיר משתני סביבה `MISHELANU_USER` ו־`MISHELANU_PASSWORD`.

## מבנה

| נתיב | תוכן |
|---|---|
| `app.py` | השרת (Flask): דפים, טפסים, הרשאות |
| `db.py`, `media.py` | מסד נתונים, טיפול בתמונות |
| `templates/`, `static/` | דפים, עיצוב, סקריפטים |
| `manifest.json`, `sw.js` | אפליקציה (PWA) |
| `data/`, `uploads/` | נוצרים בזמן הרצה — הנתונים והתמונות |

## פריסה

הנתונים נשמרים בקבצים, ולכן דרוש אחסון שנשמר בין הפעלות: PythonAnywhere, או Render עם דיסק.

## קישור מהאתר הקיים

להוסיף בתפריט של האתר הקיים קישור לכתובת של mishelanu. אין צורך בשום חיבור אחר בין האתרים.
